# Pulso

**🇧🇷 Português** · [🇺🇸 English](#english) · [🇪🇸 Español](#español)

Monitor de hardware para Windows. Junta num programa só o que normalmente exige vários: as especificações de cada peça, os sensores ao vivo e ferramentas para diagnosticar o computador. Não precisa instalar: é um arquivo só.

### Baixar

**[⬇ Baixar o Pulso (pacote completo)](https://github.com/himynameisdeh/Pulso/raw/main/download/Pulso-pacote-completo.zip)**

O pacote traz o programa, o driver de sensores e o manual em PDF. Extraia e abra o **Pulso.exe**.

Depois disso, o Pulso se atualiza sozinho: quando houver versão nova, aparece o botão **Atualizar** dentro do programa.

Versão atual: **2.2** · [O que mudou](atualizacao/NOVIDADES.md)

### O que ele mostra

- **Componentes:** processador, placa de vídeo, memória (pentes e slots), placa-mãe e BIOS, discos (saúde, temperatura e vida útil do SSD), monitores (avisa se estão abaixo dos Hz máximos), rede, periféricos e sistema.
- **Sensores ao vivo:** temperaturas, consumo, clocks e ventoinhas, com mínimo e máximo.
- **Programas:** o que mais pesa no processador, na memória, no disco e no vídeo, com botão para fechar.
- **Histórico:** a última hora em gráficos e gravação dos sensores em planilha (CSV).
- **Teste de desempenho:** processador, memória e disco, com comparação entre testes.
- **Drivers e BIOS:** avisa o que está desatualizado e abre o site do fabricante.
- **Mini janela nos jogos** (Ctrl+Alt+O) com uso, temperatura e FPS.
- **Alertas** de temperatura, disco cheio e memória, e **relatório em PDF** do computador.
- Modo claro e escuro, °C ou °F.

### Requisitos

- Windows 10 ou 11, 64 bits.
- Para a temperatura do processador e as ventoinhas: o driver gratuito [PawnIO](https://pawnio.eu) (o Pulso instala com um clique) e o programa aberto como administrador.

### Primeira vez

1. Abra o **Pulso.exe**. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo** (o programa não tem assinatura digital paga).
2. Aceite a permissão de administrador. Em computadores sem conta administradora, use o botão **Reabrir como administrador**.
3. Na tela **Processador**, clique em **Instalar driver de sensores**.

O manual completo, com imagens de todas as telas, vem no pacote completo.

<a id="english"></a>
## 🇺🇸 English

Hardware monitor for Windows. It brings together in a single program what usually takes several (CPU-Z, GPU-Z, HWMonitor): the specs of every part, live sensors and tools to diagnose the computer. No installation needed: it's a single file.

### Download

**[⬇ Download Pulso (full package)](https://github.com/himynameisdeh/Pulso/raw/main/download/Pulso-pacote-completo.zip)**

The package includes the program, the sensor driver and the PDF manual. Extract it and open **Pulso.exe**.

From then on, Pulso updates itself: when a new version is out, an **Atualizar** (update) button shows up inside the program.

Current version: **2.2** · [What's new](atualizacao/NOVIDADES.md)

### What it shows

- **Components:** processor, graphics card, memory (modules and slots), motherboard and BIOS, drives (health, temperature and SSD lifespan), monitors (warns when running below the maximum refresh rate), network, peripherals and system.
- **Live sensors:** temperatures, power, clocks and fans, with minimum and maximum.
- **Programs:** what is using the most processor, memory, disk and GPU, with a button to close it.
- **History:** the last hour in charts, plus sensor logging to a spreadsheet (CSV).
- **Benchmark:** processor, memory and disk, with comparison between runs.
- **Drivers and BIOS:** flags outdated items and opens the manufacturer's site.
- **In-game overlay** (Ctrl+Alt+O) with usage, temperature and FPS.
- **Alerts** for temperature, full disk and memory, and a **PDF report** of the computer.
- Light and dark mode, °C or °F.

The interface is in Brazilian Portuguese.

### Requirements

- Windows 10 or 11, 64-bit.
- For processor temperature and fans: the free [PawnIO](https://pawnio.eu) driver (Pulso installs it in one click) and the program running as administrator.

### First run

1. Open **Pulso.exe**. If Windows shows "Windows protected your PC", click **More info › Run anyway** (the program has no paid code-signing certificate).
2. Accept the administrator prompt. On computers without an administrator account, use the **Reabrir como administrador** (reopen as administrator) button.
3. On the **Processador** (processor) screen, click **Instalar driver de sensores** (install sensor driver).

La interfaz está en portugués de Brasil.

### Requisitos

- Windows 10 u 11, 64 bits.
- Para la temperatura del procesador y los ventiladores: el driver gratuito [PawnIO](https://pawnio.eu) (Pulso lo instala con un clic) y el programa abierto como administrador.

### Primera vez
